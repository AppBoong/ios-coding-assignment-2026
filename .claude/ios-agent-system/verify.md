> ios-verify 에이전트 프롬프트에 주입합니다 (`build.md`와 함께). 빌드 명령·스킴은 `build.md`가 진실 공급원입니다.

## 앱 실행 정보

- **번들 ID**: `com.appboong.jgnr-hw` (단일 타겟 `JGNR-HW`)
- **시뮬레이터 대상**: iPhone 17 Pro (build.md와 동일)
- **앱 진입 경로**: 로그인·온보딩 없음. 실행 즉시 첫 화면 = **상품 목록**(네비게이션 타이틀 "상품"). 실제 `https://dummyjson.com` 호출 — 시뮬레이터 네트워크 필요, mock 플래그 없음
  - 상세 진입: 목록 셀 탭 → `Route.productDetail(id:)` push
  - 찜 초기 상태: UserDefaults — 깨끗한 상태로 검증하려면 앱 삭제 후 재설치(`xcrun simctl uninstall booted com.appboong.jgnr-hw`)
  - 미정 — 첫 `/verify-ios` 실행 시 확정: 셀·버튼 접근성 식별자(`accessibilityIdentifier`) 부여 여부

## 자동 검증 금지 영역 (절대 조작 금지)

없음 — 공통 금지(결제 확정/삭제/외부 발송)만 적용. 이 앱은 읽기 전용 공개 API + 로컬 찜뿐이다

## 대표 검증 시나리오 (선택 — 자주 확인하는 플로우)

1. 앱 실행 → 목록에 20개 셀(상품명·가격·이미지·하트) 표시, 로딩 인디케이터 사라짐
2. 목록을 끝까지 스크롤 → 다음 20개가 붙는다(40개). 반복해도 같은 페이지가 중복 표시되지 않는다
3. 당겨서 새로고침 → 목록이 유지되고(첫 페이지로 리셋) 찜 상태가 남아 있다
4. 툴바 토글 → 2열 그리드로 전환, 같은 상품·같은 찜 상태. 앱 종료 후 재실행해도 2열 유지. 다시 1열
5. 셀의 하트 탭 → 채워짐. 셀 탭 → 상세 진입 → 상세의 하트도 채워져 있음. 상세에서 해제 → 뒤로 → 목록 셀 하트 비어 있음
6. 앱 종료(`xcrun simctl terminate`) 후 재실행 → 찜 상태 유지
7. 상세 진입 시 이미지·상품명·가격·할인율·브랜드·카테고리·평점·재고·설명 표시
8. [수동] 네트워크 끊고 실행 → 한국어 에러 문구 + "다시 시도" 버튼
